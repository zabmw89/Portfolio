# Software Engineer Portfolio

A professional portfolio website showcasing software engineering projects and skills.

## Features

- Responsive design for all devices
- Modern and clean UI
- Project showcase with filtering
- Skills visualization
- Interactive contact form
- Downloadable resume
- Detailed project pages

## Structure

- `index.html` - Main landing page
- `projects.html` - Detailed project showcase
- `resume.html` - Resume/CV page
- `style.css` - Main stylesheet
- `script.js` - JavaScript functionality

## Usage

1. Clone or download this repository
2. Customize the content with your own information
3. Replace placeholder images with your own project screenshots
4. Update links to your social media profiles and repositories
5. Deploy to your preferred hosting service

## Customization

### Personal Information

- Update name, title, and contact information in `index.html`
- Replace the profile picture in the About section
- Update social media links

### Projects

- Add your own projects to the Projects section in `index.html`
- Create detailed project descriptions in `projects.html`
- Update project images and links

### Resume

- Update your work experience, education, and skills in `resume.html`
- Add or remove sections as needed

### Styling

- Customize colors in the `:root` section of `style.css`
- Adjust fonts, spacing, and other visual elements as desired

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Variables)
- JavaScript (ES6+)
- Font Awesome for icons
- Google Fonts
